# Legacy web library snapshot

This is an incomplete library snapshot, not a standalone app: it has no package manifest or app entry point. The deployed site uses the root Next.js app and root `src/` modules. The local SQLite file, uploads, experiments, Next build output, and installed dependencies are machine/runtime state and are excluded from Git. The library source remains tracked for reference; its Prisma helper uses the current Prisma 7 SQLite adapter contract.
